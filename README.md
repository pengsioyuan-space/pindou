# pindou

用户保存的 [草莓拼豆图纸生成器](https://pd.luckiest.top/) 前端网页存档及功能检查记录。

**当前状态：前端存档，不是可独立运行的完整网站或原始源码工程。**

## 内容

- `snapshot/`：保存的 HTML、编译后的 JavaScript、CSS 和图片，共 18 个文件。保留原文件名和结构，卡密服务的默认密钥已替换为 `REDACTED_API_KEY`。
- `inspection/功能与备份评估.md`：功能清单、原站接口、资源缺失及恢复限制。
- `inspection/saved-site-audit.json`：本地原始保存件的静态检查记录；哈希对应本地原件。
- `inspection/backup-manifest.json`：本仓库存档文件的 SHA-256 及脱敏次数。

本地原始保存件未修改，未将原密钥提交到仓库。未复制浏览器的 Cookie、localStorage、IndexedDB 或账号数据。

## 已从代码确认的功能

JPG/PNG/CSV 导入；五种像素转换模式；品牌色号及自定义色板；画笔、取色、填充、矩形、镜像、去背景；文字图案；颜色用量统计；PNG 图纸和 CSV 数据导出；本地项目存储相关逻辑。

## 恢复限制

- 没有原始组件源码、依赖清单、构建工程、后端源码或数据库。
- 卡密、绑定和配置等逻辑依赖原站 API。GitHub Pages 不能执行这些后端接口。
- 缺失一个旧浏览器兼容脚本；导出图片等绝对路径资源的完整性尚未确认。
- `.js.下载` 扩展名、Next.js 运行时及原站路由需要另外验证，不能承诺直接打开即可正常编辑。
- 存档仍保留原站接口路径、统计脚本、品牌及外链，用于忠实记录原页面；运行存档时可能联系这些服务。

没有修改卡密验证流程，也没有用假成功接口替代原站服务。尚未部署或完成浏览器交互测试。

## 验证

运行 `python verify_archive.py` 校验存档文件数量、大小和哈希。该检查只验证文件完整性，不验证网页功能。

要恢复与原站一致的账号、卡密和云端功能，需要取得对应后端工程及部署配置；如果选择独立重建，应明确记录行为差异。
