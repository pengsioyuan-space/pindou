# 草莓拼豆工作台

可独立运行的拼豆图纸编辑器，包含自己的卡密管理服务。界面和功能以用户保存的原站为参照；**这是独立实现，不是原站源码或后端的完整恢复**。

## 启动

需要 **Node.js 24 或更新版本**。运行时没有第三方依赖：

```sh
node server/local.mjs
```

打开 `http://127.0.0.1:4173`，管理后台为 `/admin`。首次启动自动生成本机管理密钥，见 `.local/管理入口.txt`；数据库和密钥均保存在被 Git 忽略的 `.local/`。本机服务只监听回环地址，不能直接供其他电脑访问。

1. 用管理密钥进入 `/admin`。
2. 选择有效天数和数量，生成并下载用户卡密。明文卡密只显示一次。
3. 返回编辑器，输入新生成的卡密。
4. 导入 JPG、PNG、CSV、图纸 JSON，或创建空白画板。

## 已实现

- 图片转换：主色、平均色、误差扩散、强化合并、纯色板映射；10–500 横向格数，长边网格上限 500。
- 从保存件提取的 291 个颜色及 MARD、COCO、漫漫、盼盼、咪小窝品牌色号；色板筛选和自定义 JSON 色板。
- 画笔、取色、填充、矩形、橡皮、镜像、背景去除、颜色替换、撤销/重做、画布尺寸调整和文字生成。
- 坐标、色号、颜色高亮、每色豆数统计、缩放及全屏布局。
- PNG 图纸、CSV、图纸 JSON 导出；服务器历史图纸，同卡两个浏览器共享，最多 100 份。
- 自有卡密：首次激活开始计时，最多 2 个浏览器；1/7/30/365 天或永久卡；批量生成、列表查询、停用/恢复、重置绑定。
- 卡密在数据库中仅保存加密摘要；HttpOnly 登录 Cookie、来源校验、尝试频率限制和服务端项目权限校验。

## 卡密规则与边界

- 未激活不计时；重置绑定不延长有效期。恢复已到期卡不会使其重新有效。
- 浏览器绑定使用随机 HttpOnly Cookie；清除浏览器数据、隐身窗口或不同浏览器视为新绑定。它不是硬件指纹，不能保证防止主动复制 Cookie。
- 停用与重置立即阻止后续服务端访问。已下载到客户端的编辑器代码与本地图片处理无法远程收回，这不是 DRM 系统。
- 两个浏览器使用同一张卡时共享项目历史；不要把同一张卡卖给互不信任的用户。
- 图纸保存的是尺寸和逐格颜色，不保存原图、撤销栈或当前自定义色板；自定义色板请另行导出。
- 没有复制原站账号、手机号绑定、支付购买、VIP 群和第三方统计，也没有调用原站 API。
- 转换算法、预设和交互并不保证与原站逐像素一致。原站更高级的魔棒、框选和描图交互尚未复现。
- 尚未完成真实浏览器点击、视觉或 WebMCP 验收；当前工具连接不可用。

## 服务端与部署

- `public/`：独立前端；`server/api.mjs`：公共服务逻辑。
- `server/local.mjs` + `server/sqlite.mjs`：Node 24 和 SQLite 本机运行。
- `server/worker.mjs`：Cloudflare Worker 入口；Sites 使用 D1 `DB` 绑定。
- `db/schema.ts`、`drizzle/`：数据库 schema 和版本化迁移；已经应用的迁移不能覆盖重写。
- 生产必须设置独立的 `ADMIN_KEY`（至少 20 个随机字符）和 `APP_SECRET`（至少 32 个随机字符），并启用 HTTPS。不要更换 `APP_SECRET`，否则已生成的卡密摘要和登录状态不再匹配。更换管理密钥会使管理员会话失效。
- 不要把 `.local/`、数据库、管理密钥或新生成的卡密提交到 GitHub。
- GitHub Pages 只能托管静态文件，**不能运行本项目的卡密和数据库服务**。

## 验证与构建

```sh
node --test tests/*.test.mjs
node scripts/build.mjs
```

测试涵盖双浏览器并发激活限制、到期/停用、重置不延期、跨卡数据隔离、CSRF 和尝试频率限制，以及 CSV、透明色、背景连通性、五种转换模式和大图纸存储。

生成新数据库迁移才需要安装开发依赖：`pnpm install --frozen-lockfile`，然后 `node node_modules/drizzle-kit/bin.cjs generate`。运行和构建不依赖这些开发包。

## 原始存档

`snapshot/` 保留原网页的脱敏编译产物，仅供对照，不参与新站构建。原有完整性说明见 `inspection/`。运行 `python verify_archive.py` 可检查存档未被更改。原站素材和色号数据保留其原有权利归属，本仓库不另行为其声明开源许可。
